!!! warning "TestNet names end in `.paseo`, not `.dot`"
    dotNS top-level domains are per network. On Paseo Next v2, the TestNet the Apps tooling targets by default, names are minted under `.paseo`: publish `myproject57` and you get `myproject57.paseo`, served at `https://myproject57.paseo.li`. Wherever you supply a name yourself, pass the bare label (`myproject57`) and let the tooling append the environment's TLD; a name that already carries a different TLD is rejected with an actionable error.
