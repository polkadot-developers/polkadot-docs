# Vendored Vale rules

These Vale rules and the style guide vocabulary are vendored (copied) from
[`paritytech/documentation-style-guide`](https://github.com/paritytech/documentation-style-guide)
so this repository's linting is self-contained and does not depend on an
external repo at lint time.
